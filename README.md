## 📁 Repository Structure

This repository is organized into two main directories:

  * **/starter_files:** This folder contains all the Jupyter Notebooks (`.ipynb` files) that will be used for in-class demonstrations and assignments. Notebooks are organized by topic or week.
  * **/data:** This folder contains the datasets (usually in `.csv` format) that are used in the corresponding Jupyter Notebooks.

## 📖 How to Use the Materials

The Jupyter Notebooks are your primary learning resource. Each notebook is a self-contained document that includes code, explanations, and visualizations.

  * **Follow Along in Class:** During our sessions, you can open the relevant notebook and run the code cells as we go.
  * **Experiment and Explore:** You are highly encouraged to experiment with the code. Change the parameters, try new functions, and see what happens. This is one of the most effective ways to learn.
  * **Complete Assignments:** Notebooks will typically contain exercises or assignments for you to complete.

## 🤔 New to Git and GitHub?

Git and GitHub are powerful tools for version control and collaboration. Here are a few basic concepts to get you started:

  * **Git:** A version control system that tracks changes to your files over time. It allows you to revert to previous versions of your code and see who changed what.
  * **GitHub:** A web-based platform that hosts Git repositories. It's a place to store your code, collaborate with others, and showcase your projects.
  * **Repository (Repo):** A project's folder. This repository contains all the files for our course.
  * **Cloning:** This is how you get a local copy of a remote repository.
  * **Pulling:** If the course materials on GitHub are updated, you can "pull" those changes into your local copy to keep it up-to-date. In your repository folder, you can run `git pull` to do this.

You won't need to be a Git expert for this course, but understanding these basics will be very helpful.
